# 93601V deprecated code

Archive of code the team no longer uses. **Nothing here is for the current robot.**
The current code is on the `main` branch.

| Folder | What it is |
|---|---|
| `old-robot/` | The earlier robot: 4-motor tank drive with a lift, claw and spin claw. `drivetrain`, `auton`, `Comp`, `CompV2`, `OldDrivetrainComp`, plus the old README with the original auton plan. |
| `x-drive/` | The X-drive version of this season's robot (Nov 2026), newest copy: `XDrive` (driver, field-centric) and `XDriveComp` (Override autons, side toggles, 22W lift, 36:60 gearing). Ports: FL 10, FR 20, BL 9, BR 19, inertial 12, lift 1 + 2, side toggles 3 + 4. `ROBOT.md` is the X-drive handoff notes. |

Older versions of every file are in the git history (for example the first
X-drive competition code was called `OverrideComp`).
